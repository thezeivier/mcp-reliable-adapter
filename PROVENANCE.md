# Provenance

This repository is a clean-room portfolio project created from a generic systems-design brief:
demonstrate how an MCP tool can accept a request durably and deliver it to an unreliable SaaS.

- The implementation, tests, names, sample data, and documentation were written specifically for
  this repository.
- Development used AI coding assistance. Fernando Beizaga directed the design, reviewed the
  resulting source and claims, and validated the tests and build. AI assistance does not change
  the clean-room boundary below.
- No employer or client source code, prompts, schemas, credentials, customer data, internal names,
  or proprietary documentation were used.
- The fake SaaS is fictional and all identifiers in the examples are synthetic.
- The project depends on the public, official Model Context Protocol Python SDK and Python's
  standard-library SQLite module.

Before using this design in production, conduct an independent security, privacy, reliability, and
licensing review appropriate to the target environment.
